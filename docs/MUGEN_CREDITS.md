# Créditos dos assets MUGEN

- campo `author` dos arquivos `.def` em `assets/characters/`, `assets/stages/`,
  `assets/data/`, `assets/kof98data/` e `assets/fonts/`;

## 7. Observações

- `assets/characters/choi-kofa/choi-kofa.def` declara `author = "H"` com uma
  aspa não fechada; o nome foi tratado como **H"**.
- `assets/characters/BILLY/BILLY.DEF` grafa **"Conversion Wolrd - J.Lee"**;
  provavelmente "Conversion World", mas o valor original foi preservado.
- Os quatro KFM em `assets/characters/_excluded/` são de **Elecbyte** e estão
  fora do roster.
- Assets gerados pelo port (`build/gen_*`, `kof98-snes.msu`) derivam desses
  pacotes e mantêm os mesmos créditos.
